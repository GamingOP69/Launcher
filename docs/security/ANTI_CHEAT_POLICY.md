# Samrat Client — Fair-Play Feature Policy

This is the project's intended feature policy, not a claim that a server approves the client or that listed features are implemented. The packaged Forge 1.8.9 integration reaches the main menu in CI. The only implemented in-game features are an informational HUD and an opt-in static crosshair; in-world behavior is not yet hardware-verified.

## Explicit Non-Features (Strictly Prohibited)

The following categories of features are strictly rejected and will never be implemented:
- **Combat Automation**: KillAura, TriggerBot, Aim Assist, Auto-Clickers, Velocity manipulation / Anti-Knockback, Reach expansion, Criticals manipulation.
- **Movement Cheats**: Fly, Speed, Scaffold, Jesus/Water-Walk, Step hacks, FastLadder.
- **Visual Exploits**: Player ESP, Chest ESP, X-Ray, Cave Finder, Tracers.
- **Exploits & Network Tampering**: Packet spamming, Blink, Phase/NoClip, Server disablers.
- **Cracked Account / Auth Bypasses**: Bypassing Microsoft authentication, generating fake sessions, offline UUID impersonation against online servers.

## Allowed Feature Direction (Informational & Aesthetic Only)

Currently implemented:
- Informational FPS, coordinates, facing, movement-key, and sprint HUD.
- Static four-arm custom crosshair.

Other client-side HUD, animation, or cosmetic ideas remain proposals until implemented and tested against real 1.8.9 events. Do not display simulated values as live game data.

Every future feature must remain client-side and fair-play and be reviewed against the target server's current rules. A feature being informational or cosmetic does not establish server approval, compliance, or anti-cheat safety. The project does not guarantee acceptance by Hypixel or any other server.
