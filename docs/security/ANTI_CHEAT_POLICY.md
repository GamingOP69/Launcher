# Samrat Client — Anti-Cheat Compliance & Legitimacy Policy

The **Samrat Client** is engineered strictly as a legitimate utility client for PvP and Bedwars players.

## Explicit Non-Features (Strictly Prohibited)

The following categories of features are strictly rejected and will never be implemented:
- **Combat Automation**: KillAura, TriggerBot, Aim Assist, Auto-Clickers, Velocity manipulation / Anti-Knockback, Reach expansion, Criticals manipulation.
- **Movement Cheats**: Fly, Speed, Scaffold, Jesus/Water-Walk, Step hacks, FastLadder.
- **Visual Exploits**: Player ESP, Chest ESP, X-Ray, Cave Finder, Tracers.
- **Exploits & Network Tampering**: Packet spamming, Blink, Phase/NoClip, Server disablers.
- **Cracked Account / Auth Bypasses**: Bypassing Microsoft authentication, generating fake sessions, offline UUID impersonation against online servers.

## Allowed Features (Informational & Aesthetic Only)
- Client-side framerate, ping, CPS, and keystroke HUD overlays.
- Potion effect timers and armor durability percentages.
- Custom crosshair styling and hit flash color shaders.
- Precalculated FastMath trigonometric lookup tables and entity distance culling.
- Bedwars team status matrix and generator tier countdown timers.
