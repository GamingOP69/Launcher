## Current package-launch investigation (2026-10-11)

The first stronger smoke run [38143300161](https://github.com/GamingOP69/Launcher/actions/runs/38143300161) on `792f0a4` failed closed because 1.8.9 Mojang metadata uses `launcher.mojang.com`, which was absent from `ARTIFACT_HOSTS`. The allowlist fix passed CI and the installer completed in [38143874923](https://github.com/GamingOP69/Launcher/actions/runs/38143874923). The package then launched Mojang's `net.minecraft.client.main.Main` on Java 8, but [38145836336](https://github.com/GamingOP69/Launcher/actions/runs/38145836336) showed the hosted Windows VM has no usable OpenGL context (`OpenGL: No OpenGL context found in current thread`) and Minecraft exited before creating a window. The CI smoke now uses a pinned Mesa 24.0.5 `llvmpipe` software renderer beside CI Java only; it is not shipped with the product and cannot validate a physical GPU. This retry awaits Actions. No real Tauri-launched Minecraft window has passed yet.
